About

Beifahrer lets an AI agent work in your own browser, with your own sessions and the tab you are looking at, instead of in a separate automated one.

A browser extension talks to a local MCP bridge. Every site is covered by a policy you set, and anything the policy does not allow is refused.

  • Works in Firefox and Chromium-based browsers
  • Per-site policy: allowed, ask first, or forbidden
  • Confirmation prompts for actions you have not pre-approved
  • Local only: the bridge runs on your machine

Permissions

Asked when you install

  • tabs See the address and title of your tabs
  • storage Store its own settings and data
  • alarms Schedule work to run later or repeatedly
  • sessions Read and restore recently closed tabs and windows
  • tabGroups Read and change your tab groups
  • scripting Run code in pages you allow it on Only in Chromium, Edge, Safari
  • offscreen Run a hidden page for background work Only in Chromium, Edge

Asked only when needed

The browser asks you first, when a feature needs it. You can say no.

  • webRequest See and handle the requests pages make
  • downloads Manage your downloads
  • http://*/* Read and change your data on all websites
  • https://*/* Read and change your data on all websites
  • <all_urls> Read and change your data on all websites
