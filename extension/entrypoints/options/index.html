Pairing

Run beifahrer token on this computer and paste what it prints. The token proves to the bridge that it is talking to this extension and not to a web page.

Every agent session listens on its own port of this range, and beifahrer connects to each one it finds. The sessions must use the same range (BEIFAHRER_PORT, BEIFAHRER_PORT_COUNT) and the same token.

Pause

Also from the toolbar popup, the Stop button on a page the agent is working on, or Alt+Shift+B. Only you can resume: the agent cannot.

What the agent may use

One switch per capability, for the whole browser. The level you set for each site still applies on top.

Screenshots

Chromium only takes a screenshot with access to all sites. beifahrer still takes one only on sites you set to Read or higher.
